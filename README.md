# Web Analytics Tool Berbasis Python

## Deskripsi
Proyek ini merupakan tugas mata kuliah **Data Mining** yang bertujuan untuk melakukan **analisis performa dan struktur website** menggunakan **Web Analytics Tool** berbasis Python.  
Aplikasi ini mampu menganalisis website berdasarkan **input URL, periode waktu, batasan halaman, dan kedalaman crawl**, serta menghasilkan **laporan performa dan SEO** dalam bentuk **grafik dan file laporan**.

## Fitur Utama
- Analisis struktur halaman web (title, meta description, keywords)  
- Analisis SEO sederhana (jumlah link internal & eksternal)  
- Analisis performa (waktu respon & ukuran halaman)  
- Menampilkan kata yang paling sering muncul  
- Visualisasi hasil dengan **Matplotlib**  
- GUI interaktif berbasis **Tkinter**  
- Menyimpan hasil analisis ke **CSV**, **grafik PNG**, dan **laporan ringkasan TXT**  
- Mendukung input:
- URL website
- Tanggal awal & akhir (periode analisis)
- Maksimal halaman yang di-crawl
- Kedalaman link (depth)
- Timeout request per halaman
